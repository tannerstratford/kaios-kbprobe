KB Probe

Read-only. Lists how the phone's apps (including the keyboard) are registered — manifest URL, update URL, removable, status. It installs, changes and removes nothing else.

Install

On the phone, open the package manifest to install the signed app the usual way:

Apps-directory/KBProbe/update.webmanifest

Then open KB Probe from the launcher. It runs automatically and shows the dump. Up/Down scroll, Backspace exits.

What to read back

The KEYBOARD block: removable · updateUrl · status · origin — this tells us whether the keyboard could be replaced without root.

If the app shows a permission/denied error instead, a sideloaded app can't reach AppsManager on this build.
